# Launch thread draft

1. AI coding agents can build a lot. But when they ask “Which database?”, “How should auth work?”, or “Where does this run?”, you still need a mental map. I built code-tutor for that: A Map for Post-AI Builders.

   **Attach:** `demo.gif`

2. It’s a cozy 16-bit-RPG-style map with 8 regions: Languages, Databases, Infra/Hosting, AI Types, PM Tools, Git, Security, and Design Systems. Each region has 6 landmarks—48 concepts total.

   **Attach:** `screenshots/home-desktop.png`

3. Each landmark covers what it is, when to use it, honest tradeoffs, a real example, agent-aware gotchas, and a decisive “vibe-coder default.” Then there’s a deterministic quiz to check whether the idea landed.

   **Attach:** `screenshots/landmark-quiz.png`

4. Choose the depth you need: a quick overview, a full lesson, or an AI guide chat grounded in the landmark. The authored material and quizzes are the stable core; the guide can still get things wrong.

   **Attach:** none

5. This isn’t a bootcamp or interview prep. It won’t replace building, debugging, or primary docs. It’s an opinionated concept map for people already shipping with agents who want to understand the decisions underneath the generated code.

   **Attach:** `screenshots/home-mobile.png`
