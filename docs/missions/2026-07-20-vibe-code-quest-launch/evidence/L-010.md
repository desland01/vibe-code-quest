### 2.3 Credential findings that *reduce* what the owner must do

Two of the plan's prerequisites turned out not to be prerequisites:

- **`AI_DRILL_SECRET` does not need minting.** `app/api/guide/route.ts:70` passes
  `process.env.AI_DRILL_SECRET ?? ''`, and `parseDrillHeader` returns `{ kind: 'ignored' }` on
  an empty secret. Unset simply means the failure-drill harness is disabled — the correct
  production posture. EXECUTION_PLAN §9.4 can be dropped.
- **`AI_GATEWAY_API_KEY` is no longer a hard dependency.** L-009 fixed the credential guard to
  accept the `VERCEL_OIDC_TOKEN` that Vercel injects automatically
  (<https://vercel.com/docs/ai-gateway/authentication-and-byok>). A Vercel deployment can
  therefore authenticate to the gateway with no key set at all. Setting one is still the owner's
  option, not an obligation.

That leaves **`DATABASE_URL` and `AUTH_SECRET`** as the only production environment variables
the app genuinely needs for hosted mode. Everything else in `.env.example` has a working
default or degrades gracefully.

### 4.1 The G-8 criterion — the one that matters most

**A real guide turn must return model-generated text on the production URL — not the offline
banner — captured as evidence.**

This is the criterion added in answer to G-8 (recommended option adopted; see `HANDOFF.md` §4).
It exists precisely because a visual pass cannot tell a working guide from a broken one, which
is exactly how the invalid-model-id defect survived undetected until the grill.

Nothing in this repository has ever executed a real gateway request. L-009 fixed the two reasons
it could not (invalid ids, and a credential guard that ignored OIDC), but **the fix is unproven
until this smoke runs.** If the guide still returns the offline banner in production, the
gateway request is failing for a third reason and L-009 is not actually finished.

While running it, record the observed latency of a guide turn. If turns routinely approach or
exceed 8 s, set `AI_REAL_MODEL_TIMEOUT_MS` above the default and raise `GuideChat`'s 12 000 ms
client abort to keep the server ahead of it — the coupling is documented at
`src/server/ai.ts`. This is the deliberate follow-up left open by grill defect #9.
