## Design (locked)

| Surface | Behavior |
|---|---|
| Opt-in handle | 3–24 chars; letters/numbers/space/_/-; alnum start/end; no @/URL/control/phone-like |
| Boards | Weekly + all-time; top-N (25) + own rank when opted in |
| Scores | Server-derived from `xp_awards` only (never client-authoritative) |
| Soft opt-out | `opted_in=false` keeps row so mutation cooldown cannot be wiped via DELETE+rejoin |
| Handle uniqueness | Case-insensitive among **active** participants only (partial unique index) |
| Mutation cooldown | 10s profile lock between join/rename/rejoin |
| Write-abuse | HMAC-SHA256 of IP/session identity → `leaderboard_register_write`; max 20/hour; never stores raw IP |
| No-DB / self-host | GET returns empty + `unavailable`; PUT/DELETE refuse hosted writes |
| Copy | Positive-only (`leaderboard_shame_copy == false`); no red/negative deltas |
| PII | Handles only on board; no email/profile_id/timestamps in API payload |

## API

| Method | Path | Auth | Notes |
|---|---|---|---|
| GET | `/api/leaderboard?period=weekly\|all_time` | optional | Public board; anon has no `own`/`isSelf` |
| PUT | `/api/leaderboard` `{ handle }` | required | Join/rename; 409 taken, 429 cooldown/write-cap |
| DELETE | `/api/leaderboard` | required | Soft leave; not write-limited |
